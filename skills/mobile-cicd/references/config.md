# config.json reference

`.github/mobile-cicd/config.json` holds every setting the templates use. `detect.mjs --write`
drafts it and `render.mjs` validates it. Unknown fields are ignored.

## Stack

| Field | Values | Notes |
| --- | --- | --- |
| `framework` | `capacitor`, `expo`, `react-native` | |
| `nativeProjects` | `committed`, `prebuild` | `prebuild`: `ios/` and `android/` are generated by `expo prebuild` in CI (gitignored). `committed`: they are in git (Capacitor, bare React Native, Expo bare). |
| `packageManager` | `npm`, `pnpm`, `yarn`, `yarn-berry` | Picks the install, cache and audit commands |
| `installCommand` | string, optional | Overrides the install command, e.g. `npm install` when there is no lockfile |
| `pnpmVersion` | string, optional | Only when package.json has no `packageManager` field |
| `nodeVersion` | e.g. `"22"` | |
| `javaVersion` | `"17"` or `"21"` | Capacitor 7+ needs 21; React Native / Expo use 17 |
| `rubyVersion` | e.g. `"3.3"` | For fastlane |

## CI

| Field | Notes |
| --- | --- |
| `ci.lint`, `ci.format`, `ci.typecheck`, `ci.test`, `ci.build` | Full commands, or `null` to skip. Multi-line values are fine. |
| `hooks.afterInstall` | Runs after the install in CI and in both release build jobs. Use it for build prerequisites, e.g. compiling local Capacitor plugins. It never gets store secrets. |
| `web.buildCommand` | Capacitor only: the build that runs before `npx cap sync` and must produce `web.webDir`. Apps that are also a website often have a separate mobile build (`build:mobile`); detect prefers it. |
| `web.webDir` | Capacitor only, informational: the folder `cap sync` copies (from capacitor.config). |

Project-specific CI jobs that don't fit these steps (database tests, a local Supabase stack, edge
functions) belong in `ci.yml` as extra jobs. Re-add them after every re-render (or keep the
merged file and diff on re-render).

## iOS

| Field | Example (Capacitor) | Notes |
| --- | --- | --- |
| `ios.bundleId` | `com.example.app` | Must match the App Store Connect app |
| `ios.teamId` | `ABCDE12345` | Apple Developer -> Membership |
| `ios.xcodeproj` | `ios/App/App.xcodeproj` | Signing settings are applied here during the build (not committed) |
| `ios.workspace` | `ios/App/App.xcworkspace` or `null` | `null` when there is no CocoaPods workspace (SPM-only Capacitor) |
| `ios.scheme`, `ios.target` | `App` | The app target only. Extension targets need extra profiles (not handled yet). |
| `ios.infoPlist` | `ios/App/App/Info.plist` | Literal version values are rewritten here; `$(MARKETING_VERSION)` style is left alone |
| `ios.podInstall` | `pod install`, `bundle exec pod install`, `null` | `null` for Capacitor (`cap sync` installs the pods) |

## Android

| Field | Example | Notes |
| --- | --- | --- |
| `android.packageName` | `com.example.app` | Must match Play Console |
| `android.dir` | `android` | |
| `android.appGradle` | `android/app/build.gradle` | `versionCode` / `versionName` are rewritten here in committed projects; they must be literals |
| `android.aab` | `android/app/build/outputs/bundle/release/app-release.aab` | Where Gradle writes the bundle; `android-build` copies it (with `mapping.txt` and native symbols) into the artifact that `android-release` signs |
| `android.reactNativeArchitectures` | `null` or `"arm64-v8a,armeabi-v7a"` | React Native only. Fewer ABIs = much faster C++ builds; x86 builds serve only emulators and Chromebooks |

## Expo (prebuild only)

| Field | Notes |
| --- | --- |
| `expo.appJson` | Where `set-versions.mjs` writes `version`, `ios.buildNumber` and `android.versionCode` before prebuild. An `app.config.*` must take these from it, not set its own. |

## Build environment and Firebase

| Field | Notes |
| --- | --- |
| `env` | `null`, or `{ "secret": "ENV_PRODUCTION", "file": ".env.production", "required": ["VITE_..."] }`. CI writes the secret's content to `file` before building. `required` lists the variables the code reads; the setup script warns when the file lacks one. |
| `firebase.ios`, `firebase.android` | `null`, or `{ "path": "..." }` when that config file is gitignored and must come from a secret (`GOOGLE_SERVICE_INFO_PLIST` / `GOOGLE_SERVICES_JSON`, base64). |

## Release

| Field | Default | Notes |
| --- | --- | --- |
| `release.iosSubmitForReview` | `true` | `false`: upload only |
| `release.iosAutomaticRelease` | `true` | `false`: press "Release" after approval |
| `release.iosUsesNonExemptEncryption` | `false` | Export compliance answer. Most apps (HTTPS only) are `false`. Ask the user if unsure. |
| `release.androidRollout` | `1.0` | Below 1.0 is a staged rollout |
| `release.defaultNotes` | `Bug fixes and improvements.` | "What's New" when the tag has no message |

The first three and `androidRollout` become the `env:` switches at the top of
`mobile-release.yml`. Editing them there directly is fine too, but render will put the config
value back.
